# Анализатор access.log

Скрипт `analyze_logs.py` анализирует файлы веб‑логов формата Apache `access.log` и выводит статистику по запросам, а также сохраняет детальный отчёт в JSON.

## Возможности

- Подсчёт общего количества запросов.
- Распределение запросов по HTTP‑методам (GET, POST, PUT, DELETE, OPTIONS, HEAD).
- Топ‑3 IP‑адресов по количеству запросов.
- Топ‑3 самых долгих запросов (по времени ответа в мс).
- Поддержка анализа как отдельного файла, так и всей папки с логами.
- Результат выводится в терминал и сохраняется в JSON‑файл.

## Требования

- Python 3.9+ (в проекте используется Python 3.13).
- Стандартная библиотека (дополнительные зависимости не требуются).

## Установка

Никаких дополнительных пакетов устанавливать не нужно — скрипт использует только стандартные модули Python.

## Использование

### Анализ одного файла

```bash
python analyze_logs.py access.log -o stats

```
### Анализ всех log файлов в папке
```bash
python analyze_logs.py ./logs -o stats
